# Contributing

Before submitting a change, read the repository's own README and contribution instructions. Local guidance takes precedence over this account-wide default.

- Open an issue for substantial or ambiguous changes; a short idea is welcome without a complete specification.
- Keep pull requests focused. Explain the problem, change, verification, and relevant risks.
- Report what actually ran. Do not claim a green test or deployed result without evidence.
- Never post secrets, private logs, personal data, production addresses or access tokens in public issues or pull requests.
- Repository labels and triage status do not grant an automated agent permission to execute, merge or deploy.

A repository may have a more specialized workflow, review gate or security process.
