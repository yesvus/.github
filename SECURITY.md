# Security policy

Please do **not** disclose a vulnerability, exploit, credential or sensitive log in a public issue or pull request.

If the affected repository has **Private vulnerability reporting** enabled, use its **Security > Report a vulnerability** flow. Otherwise contact its maintainer through an existing verified, non-public communication channel.

This is the account-wide fallback policy. Individual repositories may publish their own reporting and supported-version policy. Do not assume a private reporting channel is enabled for every repository.
